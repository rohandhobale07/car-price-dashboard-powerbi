# 🚗📊 Car Price Analysis & Predictive Dashboard 🚗📊

An interactive Power BI dashboard designed to analyze automobile pricing patterns and compare **actual vs predicted MSRP** across different car makes, models, body styles, horsepower, and torque.

## 📌 Project Overview

This project analyzes car pricing data using **Power BI and Excel** to identify pricing patterns and relationships between vehicle specifications and MSRP.

The dashboard provides interactive analysis of **1,610 car records**, covering multiple makes, models, body styles, and vehicle specifications.

The analysis focuses on comparing actual and predicted MSRP, analyzing price differences across models and brands, and understanding how **horsepower and torque relate to vehicle pricing**.

## 🎯 Project Objectives

* Analyze car prices across different makes and models
* Compare **Actual MSRP vs Predicted MSRP**
* Analyze the relationship between horsepower, torque, and MSRP
* Identify pricing patterns across different body styles
* Build an interactive dashboard for car price analysis
* Provide KPI-driven insights for automobile pricing analysis

## 🛠️ Technologies Used

### 📊 Power BI

* Actual vs predicted price analysis

### 📗 Microsoft Excel

## 📁 Dataset

* 📊 **1,610 car records**
* 🔑 Key fields: Make, Model, Year, MSRP, Used/New Price, Body Size, Body Style, Horsepower, Torque
* 📈 Includes actual and predicted MSRP values
* 🚘 Covers **7 car makes**
* 🚗 Covers **150 car models**
* 📋 Includes **12 body styles**

## ⚙️ Data Analysis

The project analyzes vehicle pricing using multiple dimensions:

* **Make & Model Analysis**
* **Actual vs Predicted MSRP**
* **Horsepower vs MSRP**
* **Torque vs MSRP**
* **Body Style Analysis**
* **Average MSRP Analysis**

Interactive slicers allow users to filter the dashboard by:

* Make
* Model
* Body Size
* Body Style

## 📊 Dashboard Design

The Power BI dashboard includes:

* KPI cards for Number of Cars

* Actual vs Predicted MSRP by Model
* MSRP vs Horsepower scatter plot

## 📈 Key Findings

* 💰 **Average Actual MSRP:** $72,542
* 🤖 **Average Predicted MSRP:** $72,603
* 📊 **R²:** 0.90
* 📉 **MAE:** $10,697
* 📈 **RMSE:** $17,248
* 🚘 **Car Makes Analyzed:** 7
* 🚗 **Car Models Analyzed:** 150
* 📋 **Body Styles Analyzed:** 12

## 💡 Key Business Insights

* Actual and predicted MSRP values can be compared to evaluate pricing accuracy.
* Car pricing varies across different makes and models.
* Horsepower can be analyzed against MSRP to identify pricing relationships.
* Torque provides another vehicle-performance dimension for understanding price variation.
* Interactive filtering allows users to drill down into specific vehicle categories.
